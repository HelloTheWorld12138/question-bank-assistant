# 批量导入与离线 OCR

批量导入中心用于把教师已有的 DOCX、PDF、扫描件和照片转换成“待审核草稿”。任何草稿都必须由教师勾选“已对照原文核对”后才能进入正式题库。

## 支持范围

| 输入 | 当前处理方式 | 无 OCR 时 |
|---|---|---|
| DOCX | Pandoc 提取正文和图片，再按原题号初步切分 | 可用 |
| 数字 PDF | PyMuPDF 提取文字和内嵌图片 | 可用 |
| 扫描 PDF | 页面渲染为 PNG，使用本地 PaddleOCR 识别 | 保留整页原图，等待人工录入 |
| PNG/JPG/WEBP/BMP/TIFF | 自动纠正 EXIF 方向，可旋转、裁剪、增强和透视校正 | 保留原图，等待人工录入 |
| 答案或解析卷 | 优先按原题号匹配，题数相等时才按顺序回退 | 未匹配项醒目标记 |

数字、单位、上下标、公式、电路图和坐标图都属于高风险内容。软件不会把 OCR 结果直接写入正式题库，也不会在没有教师确认时猜测答案。

## 两种开发运行方式

基础依赖：

```bash
python -m pip install -r requirements.txt
```

完整离线 OCR 依赖：

```bash
python -m pip install -r requirements-ocr.txt
```

PaddleOCR 还需要与目标系统和处理器匹配的 PaddlePaddle 运行时。现阶段不在教师电脑上自动联网下载模型；第七阶段制作 Windows 发行包时再固定 PaddlePaddle 版本、预下载模型并校验离线启动。

## 教师审核流程

1. 在“批量导入中心”选择题目文件，可另选答案或解析文件。
2. 点击“分析并生成草稿”。
3. 逐题检查正文、答案、解析、板块、类型、题型和知识点。
4. 必要时使用旋转、裁剪、去阴影增强、透视校正、合并或拆分。
5. 对照原文确认无误后勾选“已对照原文核对”。
6. 点击“确认所选入库”。

“保存审核草稿”只保存中间结果，不会占用正式题号；正式题号只在确认入库时分配。

## 离线与国内网络

- DOCX、数字 PDF、图片处理、切题、匹配和正式入库都可离线运行。
- PaddleOCR 安装完成且模型已预下载后可完全离线识别。
- 基础版没有 OCR 时不会请求境外服务，而是保留原图并转入人工审核。
- 云模型分类属于可选功能，与 OCR 导入互不依赖。

## 当前限制

- 自动切题依赖常见的 `1.`、`2．`、`第3题` 等题号格式，复杂双栏版面可能需要人工合并或拆分。
- 公式图片仍沿用“保留原图 + 可选公式 OCR + 教师确认”的策略。
- 手写体、模糊拍照和复杂表格的识别质量取决于原图，不能跳过人工核对。
- 标准版与完整离线 OCR 版的最终安装包属于第七阶段，本阶段只完成代码、依赖分层和运行模式。
