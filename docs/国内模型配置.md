# 国内模型与本地模型配置

AI 是可选增强。没有 API Key、没有网络或模型服务故障时，手动录题、Word 导入、
题库搜索、组卷、导出和备份仍可使用。

## 支持的服务

| 服务 | 默认地址 | 默认模型 | 适用情况 |
|---|---|---|---|
| 阿里云百炼 / 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3.7-plus` | 中国内地网络默认推荐 |
| DeepSeek 官方 API | `https://api.deepseek.com` | `deepseek-v4-flash` | 中国内地可选 |
| 自定义 OpenAI 兼容接口 | 教师填写 | 教师填写 | 学校代理、LM Studio 或其他兼容服务 |
| Ollama | `http://127.0.0.1:11434` | `qwen3:8b` | 完全本地，不发送到云端 |

模型名称和服务状态可能变化，界面允许修改。上表依据 2026-07-26 的官方文档：

- [阿里云百炼结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)

## 教师端设置

1. 打开网页底部“AI 辅助设置（可选）”。
2. 选择服务。
3. 云端服务填写 API Key；Ollama 不需要。
4. 点击“保存设置”。
5. 点击“测试连接”。
6. 回到题目审核区，点击“生成分类建议”。

如果使用 LM Studio，可选择“自定义 OpenAI 兼容接口”，通常填写本机提供的
OpenAI 兼容地址（例如 `http://127.0.0.1:1234/v1`）和已经加载的模型名称。

## 隐私边界

- API Key 通过 Python keyring 写入操作系统凭据存储；Windows 使用 Credential Locker。
- `vault/settings.json` 只保存服务地址、模型名、超时和开关，不保存 API Key。
- 调用云模型前，界面会明确询问是否发送当前题目正文。
- 不发送答案、解析、图片、其他题目或整个题库。
- AI 只做分类，不解复杂题，不生成或覆盖教师答案。
- 返回结果必须通过 JSON Schema 和固定分类字典校验。
- 合法结果保存到 `vault/ai_drafts/` 的待确认记录，并填入审核区；只有教师点击
  “确认入库”后才会写入正式题库。

## 国内网络和断网

“只使用本地功能”会阻止云模型调用。断网或云服务错误时，界面给出中文提示，
不会影响正式题库，也不会阻止教师手动分类。

教师正式试用前仍需在目标学校网络实测阿里云和 DeepSeek。GitHub、PyPI 和 npm
都不参与教师运行时的模型调用；最终安装包阶段会把基础依赖预先内置。
