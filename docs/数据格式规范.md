# 题库数据格式规范

本文档冻结高中物理题库助手 `schema_version: 1` 的数据契约。Markdown 是正式题库的唯一真源；缓存、搜索索引和导出文件均可由它重新生成。

## 目录结构

```text
vault/
├─ index.json
├─ backups/               # 运行时备份，不进入 Git
├─ templates/             # 教师可替换的试卷模板
├─ .trash/                # 可恢复的已删除题目
├─ 题目/
│  └─ LXCX0001.md
└─ assets/
   └─ LXCX0001_01.png
```

## 题号

题号格式为 `板块代码 + 主类型代码 + 四位流水号`，例如 `LXCX0001`。

- 题号是唯一标识；
- Markdown 文件名必须为 `题号.md`；
- 图片名必须以 `题号_` 开头；
- 题号生成后不得在普通编辑流程中修改。
- 板块和主类型由题号前缀确定，普通编辑流程不能把它们改成与题号冲突的值。

## Frontmatter

新建题目必须包含以下字段：

```yaml
---
schema_version: 1
id: LXCX0001
板块: 力学
主类型: 创新题
类型:
  - 创新题
知识点:
  - 牛顿第二定律
难度系数: '0.63'
年份: '2026'
来源: 教师自编
解析来源: 教师上传
题型: 选择题
图片:
  - LXCX0001_01.png
创建时间: '2026-07-26T10:00:00+08:00'
更新时间: '2026-07-26T10:00:00+08:00'
---
```

字段约定：

| 字段 | 类型 | 说明 |
|---|---|---|
| `schema_version` | 整数 | 当前固定为 `1` |
| `id` | 字符串 | 与文件名一致的唯一题号 |
| `板块` | 字符串 | 从固定板块字典中选择 |
| `主类型` | 字符串 | 从固定主类型字典中选择，只能有一个 |
| `类型` | 字符串列表 | 第一项为主类型，可追加其他标签 |
| `知识点` | 字符串列表 | 每项使用统一名称 |
| `难度系数` | 字符串或数字 | 唯一正式难度字段；旧字段 `难度` 只读兼容 |
| `年份` | 字符串或整数 | 可为空 |
| `来源` | 字符串 | 可为空 |
| `解析来源` | 字符串 | 默认“教师上传” |
| `题型` | 字符串 | 可选：选择题、填空题、实验题、计算题或其他 |
| `图片` | 字符串列表 | 只保存 assets 内文件名 |
| `创建时间` | ISO 8601 字符串 | 首次入库时间 |
| `更新时间` | ISO 8601 字符串 | 每次正式写入时更新 |

## 正文结构

四个一级标题固定存在且顺序固定：

```markdown
# 题目

题目正文。

# 答案

教师提供的答案。

# 解析

教师提供的解析。

# 备注

可选备注。
```

图片在正文中使用相对路径：

```markdown
![](../assets/LXCX0001_01.png)
```

公式统一使用下面两种写法：

```markdown
行内公式：$F=ma$

独立公式：

$$
E_k=\frac{1}{2}mv^2
$$
```

- 网页使用随软件提供的本地公式组件预览，不依赖外网；
- Word 中已有的可编辑公式在导入后统一为上述写法；
- 导出 Word 时转换为可继续编辑的 Word 公式；
- 公式开头和结尾不成对时不能入库，页面会提示具体位置；
- 旧版 MathType/OLE 公式优先读取 OLE 内的 MTEF 结构，转成上述可编辑公式并保持
  在正文中的原位置；
- 单个旧版公式无法读取时，只回退该公式的原始预览图，并在审核页明确标记，不影响
  同一文档中的其他公式继续转换。

图片遵守以下规则：

- 照片和常见位图在入库时统一保存为 PNG；
- Word 中普通的 WMF/EMF 题图在本机转为 PNG；MathType 公式的 WMF/EMF 预览图
  只在结构化转换失败时作为回退，不依赖境外网络；
- 图片按正文中的实际位置插入题目、答案或解析，不统一堆到文末；
- 草稿中未使用或已移除的图片不会进入正式题库；
- 默认导出宽度为页面正文宽度的 70%，已有明确宽度设置时保留原设置；
- 修改题目时可以重新放置或移除图片，移除后同时清理对应资源文件。

## 向后兼容

- 没有 `schema_version` 的旧题按版本 1 读取；
- 旧字段 `难度` 在读取时映射到 `难度系数`；
- 旧题只有在教师编辑并保存时才补充时间字段；
- 未来修改数据结构必须增加迁移程序，不能批量直接替换原文件。

## index.json

`index.json` 保存各前缀已经分配的最大序号：

```json
{
  "LXCX": 12,
  "DXJD": 8
}
```

它是编号辅助状态，不是题库真源。损坏或丢失时必须可以扫描题目文件重建。

编号分配持有跨进程文件锁，`index.json` 和 Markdown 使用原子替换写入。只有正式题目写入成功后，才确认对应流水号。

## 试卷模板

内置模板不改变题库数据格式。运行时模板位于 `vault/templates/`：

- `a4_single.docx`：A4 单栏练习；
- `a4_double.docx`：A4 双栏练习；
- `formal_exam.docx`：正式考试卷。

模板只负责页幅、边距、字体、标题、页眉页脚和分栏等样式。题目、答案和解析仍从 Markdown 真源按需生成。

复制题目时会生成新题号、复制并重命名绑定图片，同时增加可选字段
`复制自`。该字段只用于追溯，不影响搜索和组卷。
