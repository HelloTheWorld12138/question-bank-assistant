# 开发说明

教师操作请阅读根目录的《使用教程》。本文件只面向开发和测试。

## 环境

- Python 3.10+
- Windows 是主要交付平台；macOS/Linux 可用于后端开发

安装依赖：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -r requirements-dev.txt
```

Windows PowerShell 对应解释器路径为 `.venv\Scripts\python.exe`。

## 启动

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。

## 测试

```bash
.venv/bin/python -m pytest
```

测试使用临时题库目录，不应写入正式 `vault/`。

## 当前模块

```text
app/
├─ api/routes.py          HTTP 路由与参数绑定
├─ services/documents.py  DOCX 转换和结构识别
├─ services/questions.py  录题、搜索、组卷业务
├─ services/maintenance.py 回收站、完整性检查和备份恢复
├─ config.py              路径、版本和分类常量
├─ storage.py             Markdown、YAML 和索引读写
├─ errors.py              统一业务错误与异常响应
├─ logging_config.py      本地滚动日志
├─ agent.py               OpenCode 临时适配
├─ math_ocr.py            公式图片检测和 OCR
└─ main.py                应用组装和静态资源挂载
```

## 数据目录覆盖

开发或测试时可通过环境变量修改数据和导出目录：

```text
QUESTION_BANK_DATA_DIR
QUESTION_BANK_EXPORT_DIR
QUESTION_BANK_LOG_DIR
```

正式数据规范见《docs/数据格式规范.md》；架构和阶段计划见根目录《项目实施规划.md》。

应用启动时每天最多创建一次自动备份。运行期生成的 `vault/backups/`、`vault/.trash/` 和编号锁文件不进入 Git。
