# 开发说明

教师操作请阅读根目录的《使用教程》。本文件只面向开发和测试。

## 环境

- Python 3.10+
- Windows 是主要交付平台；macOS/Linux 可用于后端开发

安装依赖：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -r requirements-dev.txt
```

Windows PowerShell 对应解释器路径为 `.venv\Scripts\python.exe`。

## 启动

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。

## 测试

```bash
.venv/bin/python -m pytest
```

测试使用临时题库目录，不应写入正式 `vault/`。

## 当前模块

```text
app/
├─ api/routes.py          HTTP 路由与参数绑定
├─ content.py             录入、预览、存储和 Word 共用的换行规则
├─ services/documents.py  DOCX 转换和结构识别
├─ services/imports.py    PDF/照片/OCR、批量切题和答案匹配
├─ services/assistant.py  自然语言条件解析、候选筛选和组卷建议
├─ services/models.py     国内/本地模型适配、结构化分类和推荐排序
├─ services/office.py     OfficeCLI 串行调用、模板合并、校验和预览
├─ services/questions.py  录题、搜索、组卷业务
├─ services/maintenance.py 回收站、完整性检查和备份恢复
├─ config.py              路径、版本和分类常量
├─ storage.py             Markdown、YAML 和索引读写
├─ errors.py              统一业务错误与异常响应
├─ logging_config.py      本地滚动日志
├─ agent.py               OpenCode 临时适配
├─ mathtype.py            旧版 MathType/OLE 结构化读取与失败回退
├─ math_ocr.py            公式图片检测和 OCR
├─ cli.py                 本地题库命令行入口
└─ main.py                应用组装和静态资源挂载
```

## 数据目录覆盖

开发或测试时可通过环境变量修改数据和导出目录：

```text
QUESTION_BANK_DATA_DIR
QUESTION_BANK_EXPORT_DIR
QUESTION_BANK_LOG_DIR
```

正式数据规范见《docs/数据格式规范.md》；架构和阶段计划见根目录《项目实施规划.md》。

## 本地题库 CLI

```bash
.venv/bin/python -m app.cli status
.venv/bin/python -m app.cli parse "找5道力学创新题，约45分钟"
.venv/bin/python -m app.cli recommend "找5道力学创新题，约45分钟"
.venv/bin/python -m app.cli export LXCX0001 LXCX0002 --title "力学练习"
```

自然语言推荐默认完全本地。只有显式增加 `--ai` 才会使用模型；云模型还必须增加
`--consent`。

应用启动时每天最多创建一次自动备份。运行期生成的 `vault/backups/`、`vault/.trash/` 和编号锁文件不进入 Git。

## Word 导出工具链

```text
Markdown 题库
    ↓ Pandoc + reference.docx
DOCX
    ↓ OfficeCLI
结构读取 / 校验 / issues 检查 / HTML 预览
```

- 三套内置 reference DOCX 位于 `templates/`；
- 运行时会复制到数据目录 `vault/templates/`，教师可替换；
- “恢复默认模板”会用内置版本覆盖数据目录模板；
- OfficeCLI 路径优先读取 `OFFICECLI_PATH`，其次读取 `tools/officecli/`；
- `OFFICECLI_SKIP_UPDATE=1` 强制关闭运行时更新，避免教师端依赖外网；
- OfficeCLI 命令由全局锁串行执行，防止同一文档的驻留进程冲突；
- OfficeCLI 不可用或复核失败时保留 Pandoc 生成的 DOCX。

构建 Windows 发行包前执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_pandoc.ps1
powershell -ExecutionPolicy Bypass -File scripts\download_officecli.ps1
```

两个脚本均固定版本并校验 SHA-256。第三方许可证位于 `third_party/`。
