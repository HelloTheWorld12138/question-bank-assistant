# 高中物理题库助手

面向高中物理教师的本地题库与组卷工具。当前仓库处于从网页 MVP 向独立 Windows APP 演进的阶段。

## 当前能力

```text
手动粘贴 / DOCX / 数字 PDF / 扫描件 / 照片
        ↓
批量切题、答案匹配与草稿审核
        ↓
Markdown + 图片入库
        ↓
编辑 / 搜索 / 勾选组卷
        ↓
Markdown / Word 导出
```

题目数据保存在 `vault/题目/`，图片保存在 `vault/assets/`。Markdown 是正式题库的唯一真源。

当前版本已经支持题目复制、批量标签修改、全文搜索与排序、回收站恢复、图片完整性检查、编号索引修复、自动/手动备份，以及每次使用独立文件名导出试卷。组卷时可以调整题目顺序和展示题号、按题型分组，并分别生成题目卷、答案卷和解析卷。Word 导出可选择 A4 单栏、A4 双栏和正式考试卷模板；OfficeCLI 可在导出后执行结构校验与 HTML 预览。OpenCode、公式 OCR 和 OfficeCLI 均有明确的离线降级路径。

公式和图片已纳入完整编辑流程：输入区可插入并即时预览行内或独立公式，Word
可编辑公式会在导入时保留，导出后仍是可编辑的 Word 公式。旧版 MathType/OLE 公式
会优先在本机读取内部结构，转成可编辑公式并保留原位置；无法读取的少量公式才会保留
原图并醒目提醒教师核对。WMF/EMF 题图继续在本机转换为 PNG。上传图片可以指定放入
题目、答案或解析，也可以在入库前和后续
编辑时移除；常见位图统一保存为 PNG，试卷导出时按正文宽度稳定排版。公式预览、
MathType 转换和旧图转换组件都随项目本地提供，运行时不访问 CDN 或境外网络。
Word 中的斜体、粗体和
上下标会在预览中按格式显示，Markdown 标记不会直接暴露给教师。
录入区中的一次回车会在 Word 中保留为换行，空一行表示另起一段；从 Word 读取的
A/B/C/D 选项会自动去除多余空行和内部标记；同一行横向排列的选项（包括 Word 中
使用 Tab 排列的选项）以及“A/B 一行、C/D 一行”的两列排法，都会自动拆成一项一行，
预览与最终试卷使用同一套规则；之前已经生成的待审核草稿重新打开后也会自动整理。

可选 AI 层支持阿里云百炼、DeepSeek、自定义 OpenAI 兼容接口、Ollama 和
LM Studio。API Key 不写入题库；云端调用前需要明确确认，且只发送当前题目正文。
AI 分类结果必须先进入审核草稿，不能直接修改正式题库。

批量导入中心支持数字 PDF 文字提取、Word 多题切分、照片预处理、相邻题合并/拆分、
答案卷匹配和置信度提示。教师版答案与解析可按“答案、解析/详解、难度、来源、知识点”
等栏目辅助提取；重复出现的原题不会再次写入解析，结构不明时转人工填写。审核界面将
答案与解析合并显示，解析附图会随题保留。图片裁剪和透视使用图形化选择，去阴影可以
取消，也可一键恢复原图，处理后页面不会跳离当前题。PaddleOCR 是可选的完整离线能力；未安装时，扫描件与照片
会保留原图进入人工审核，数字 PDF、DOCX 和其余核心功能不受影响。

“搜索组卷”支持直接输入自然语言，例如“找 5 道近三年力学创新题，中等难度，
覆盖牛顿第二定律，约 45 分钟，带解析”。系统先在本机解析条件并筛选候选题，
给出预计用时和推荐理由，老师确认后才能加入组卷。模型增强排序和 AionUI Skill
都是可选层，不影响独立 APP 离线使用。

## 当前 MVP 启动

macOS 直接双击：

```text
打开高中物理题库.command
```

启动器会自动启动本地服务并打开首页。当前开发环境若尚未安装 Pandoc，会通过已安装的
Homebrew 自动补齐；正式教师版将在第七阶段把 Pandoc 内置到安装包中，不依赖教师操作
命令行或临时访问 GitHub。程序文件更新后再次双击启动器，它会自动关闭旧后台并加载
新版本，避免网页界面与后台接口版本不一致。

不再使用时可双击 `关闭高中物理题库.command`。不要直接打开 `static/index.html`，
否则浏览器只会读取页面骨架，无法连接本地题库服务。

首页按教师任务分为“导入一份资料”“录入一道题”“按要求找题”“整理并导出试卷”
四个入口；题库维护和 AI 设置从顶部导航单独进入，不需要从头到尾填写一张长表单。

Windows 可以双击：

```text
start.bat
```

开发环境启动：

```bash
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

需要在开发环境启用完整离线 OCR 时：

```bash
python -m pip install -r requirements-ocr.txt
```

打开 `http://127.0.0.1:8000`。

## 测试

```bash
python -m pip install -r requirements-dev.txt
python -m pytest
```

真实 Word、PDF 和照片样本放入 `tests/real_samples/`，该目录中的材料默认不会提交到 Git。

## 重要说明

- 当前仍是开发版，不是可直接分发给教师的正式安装包；
- OpenCode 和公式 OCR 已不再是基础导入的硬依赖；Pandoc 负责 Markdown/DOCX 转换，OfficeCLI 负责结构读取、模板能力、导出复核和预览；
- 旧版 MathType 公式采用本机结构化读取；当前开发版使用系统 Ruby，Windows 教师版将在第七阶段内置固定运行时；
- 公式预览组件已随项目本地提供，教师使用时不会临时访问境外 CDN；
- OfficeCLI 固定为 `1.0.142`，发行包构建时下载并校验哈希，教师电脑不需要连接 GitHub；
- 最终版本要求无需 Python、Node、OpenCode、Obsidian 或命令行；
- 第七阶段才制作标准版和完整离线 OCR 版安装包；当前先完成功能与验收；
- 后续开发严格按《项目实施规划》逐阶段完成。
